# ДоброМісто — оболонка застосунку

Адаптивна демоверсія платформи. Без npm, збірки та секретних ключів.

## Запуск

Відкрий `index.html`. Якщо браузер забороняє ES-модулі для `file://`, відкрий PowerShell у цій теці й виконай:

```powershell
python -m http.server 8000
```

Потім перейди на http://localhost:8000.

## Що працює

- розділи світу, історій, Добриків, місій, саду, благодійних ініціатив і профілю;
- фільтрація місій, запис, скасування та окреме демопідтвердження;
- досвід і розвиток Листика після підтверджених місій;
- власний сад, декор, перейменування профілю, експорт і скидання локальних даних;
- прогрес зберігається в localStorage;
- розділ історій порожній і підготовлений для твоїх коміксів; читач показує кадри послідовно.

Дані місій і благодійних кампаній — приклади. Записи нікому не надсилаються, пожертви не приймаються, а демопідтвердження не замінює підтвердження організатора.

## Як додати комікс

Відкрий `src/data.js` і додай об’єкт у `chapters`:

```js
export const chapters = [{
  id: 'chapter-one', number: 1, title: 'Назва глави',
  summary: 'Короткий опис', cover: '🌿',
  scenes: [
    { image: 'assets/comics/chapter-one/scene-01.jpg', narration: 'Текст сцени.', dialogue: 'Репліка героя.' },
    { image: 'assets/comics/chapter-one/scene-02.jpg', narration: 'Наступна сцена.' }
  ]
}];
```

Створи папку `assets/comics/chapter-one/` і поклади туди зображення. Для кожної сцени передбач окрему ілюстрацію, текст оповідача та за потреби репліку. Готова глава автоматично з’явиться у розділі «Історії».

## Структура

- `src/app.js` — сторінки та взаємодії;
- `src/data.js` — місії, кампанії, Добрики, глави;
- `src/store.js` — localStorage;
- `src/style.css` — дизайн і мобільна адаптивність;
- `supabase/schema.sql` — початкова схема даних;
- `.env.example` — назви майбутніх змінних без ключів.

SQL-файл є заготовкою, а не production-системою. Для справжнього запуску потрібно додати серверне підтвердження місій, налаштувати автентифікацію і перевірити RLS. Ніколи не клади service role key у браузер.
